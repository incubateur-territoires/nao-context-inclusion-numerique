# Décisions d'architecture (ADR)

Une décision actée = un fichier `NNN-titre-kebab.md`, numéroté en continu à partir de 001. Même format que les ADR de MIN (`docs/adr/` du dépôt `suite-gestionnaire-numerique`). Modèle : [000-modele.md](000-modele.md).

## Règles

- **Une décision par ADR**, rédigée au moment où elle est prise, ou extraite d'un document de travail à la clôture du chantier.
- **Un ADR accepté ne se réécrit pas.** Si la décision change, on écrit un nouvel ADR qui le remplace et on passe l'ancien en « Remplacé par ADR-XXX ».
- **Statuts** : `Proposé` (en discussion) → `Accepté` (en vigueur) → `Remplacé par ADR-XXX` ou `Abandonné`.
- **Périmètre transverse** (dataspace + MIN, coop…) : l'ADR vit dans le dépôt propriétaire de l'objet concerné, l'autre dépôt y renvoie par un lien.
- Un ADR décrit le **pourquoi**. Le **comment** à jour vit dans la doc de référence (`docs/`), qui cite l'ADR.
- Pas de données personnelles : rôles plutôt que noms d'interlocuteurs extérieurs, comptes plutôt que listes.
